# Secure Chain Solutions

1. EduVault-X – Blockchain-Based Secure Examination System

What it does: A secure examination platform combining biometric authentication with blockchain to protect exam access, records, and question-paper storage.

Technologies: Blockchain, Solidity, Ethereum/Sepolia, Hardhat, Node.js, Express.js, SQLite, React, Fingerprint/Face Authentication.

My Role: Designed and developed the blockchain integration, smart-contract functionality, backend APIs, database integration, and deployment workflow.

Achievement/Outcome: Successfully developed the backend and deployed the smart contract to the Sepolia testnet as part of an intensive development sprint.

2. SkillCertChain – Blockchain Certificate Verification Platform

What it does: A decentralized platform for issuing and verifying educational/professional certificates using blockchain and IPFS, reducing the possibility of certificate forgery.

Technologies: Solidity, Ethereum, Hardhat, React, Ethers.js, IPFS, MetaMask, OpenZeppelin.

My Role: Developed the Solidity smart contract, implemented certificate verification using blockchain/CID, integrated IPFS, and built the Web3-enabled frontend.

Achievement/Outcome: Built a functional decentralized certificate-verification prototype with blockchain-based verification.

3. GiftChain – Blockchain Donation Tracking DApp

What it does: A decentralized donation-tracking application that records donation transactions transparently on the blockchain.

Technologies: Solidity, Ethereum/Polygon, React, Vite, Ethers.js/Web3.js, MetaMask, Hardhat.

My Role: Developed the smart contract and integrated it with the React frontend, including wallet connectivity and blockchain transaction handling.

Achievement/Outcome: Developed a working DApp prototype demonstrating transparent and tamper-resistant donation tracking.

4. SafeStreets – AI-Powered Women’s Safety Companion

What it does: A safety-focused application designed to provide intelligent route recommendations, SOS activation, live location sharing, predictive safety alerts, and secure evidence storage.

Technologies: AI/ML, Location Services, Real-Time Systems, Blockchain, Mobile/Web Technologies.

My Role: Contributed to the technical architecture, blockchain-based evidence storage, safety features, and overall application development as part of a 6-member hackathon team.

Achievement/Outcome: Developed as a hackathon project focused on using AI, real-time location technology, and blockchain to improve personal safety.

5. PropGrowthX – Property Management/Web Platform

What it does: A property-focused web platform with property listings and image management backed by cloud storage and a database.

Technologies: Next.js, React, Tailwind CSS, Supabase, PostgreSQL, Supabase Storage.

My Role: Worked on the full-stack integration, including property data, database schema, Supabase Storage, property-image management, and frontend integration.

Achievement/Outcome: Implemented cloud-based property image storage and integrated property data and images into the web application.
